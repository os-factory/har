HAR turns the unwritten knowledge required to run a repository into an editable
`.har/` contract. Coding agents and developers use the same commands to create
isolated worktrees, launch services, verify changes, collect artifacts, and hand
off a validated branch.

## The shortest useful workflow

```bash
npm install -g @osfactory/har
har env init
har env launch 1
# Make changes only in the work dir printed by launch.
har env verify 1 --full
har env complete 1
```

HAR is not a coding model, test runner, or CI/CD replacement. It is the stable
operating contract that lets those systems work with a real repository safely.
